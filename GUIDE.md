# cool-resume Guide (English)

## Overview

cool-resume is a modern, stylish resume generator built with React. This guide provides documentation in English for international users.

## Features

- Multiple professional templates
- Fully responsive design
- Real-time preview
- Export to PDF
- Easy customization

## Quick Start

### Installation

```
git clone https://github.com/JeffAAA/cool-resume.git
cd cool-resume
npm install
```

### Development

```
npm run dev
```

### Build

```
npm run build
```
